# removeLiquid(amountToRemove, liquidType) → {Map.<Liquid, number>}

Removes a specified amount of liquid from the object. If liquidType is set to null, then this function removes liquids evenly, so that a total of amountToRemove is removed while keeping the ratio of liquids the same. Otherwise, it will only remove amountToRemove from the liquid type specified. This function is typically called without a liquidType specified and the specific liquid removal feature should only be used in special scenarios.
