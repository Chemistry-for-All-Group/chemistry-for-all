PageBuilder

PageBuilder(rootId, siteTitle)

Handles switching between views of an experiment. A view is a template id plus a function that returns the data to fill it with. Only one view is shown at a time, inside the root element. Clicking any element with data-view="id" (like the nav buttons) opens that view.
Constructor

# new PageBuilder(rootId, siteTitle)

Parameters:
Name Type Description
rootId String id of the element views are shown in (usually main)
siteTitle String added to the end of the browser tab title
