# releaseButane(targetIncrement)

Reduces mlOfButane by a value within 0.1 mL of targetIncrement. The actual amount of butane removed is a randomly selected number between targetIncrement - 0.1 mL and targetIncrement + 1 mL. If connectedTubing is not null (meaning there is tubing connected to the lighter), the butane will be transferred through the tubing. Otherwise, the butane will simply be removed from the lighter like normal.
Parameters:
Name Type Default Description
targetIncrement number 0.5 The desired amount of butane in mL to be released from the lighter.
