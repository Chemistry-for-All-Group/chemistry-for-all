# Chemistry for All
Accessible versions of Chemistry World experiments from Second Life designed
with blind users in mind.

Try the experiments on our [website](https://chemistry-for-all-group.github.io/chemistry-for-all/).

## Built with
- [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
- [HTML](https://developer.mozilla.org/en-US/docs/Web/HTML)
- [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)

## Features
- Molar mass of butane experiment
- Titration of bay water samples experiment
- Completely text-based
- Designed with screen readers in mind
- Lab report forms built-in to the experiments
